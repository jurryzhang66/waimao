# ============ 本轮最关键的三条技术判定（写死在这里，别再重新推导）============
# 1) ⛔ 查询导出**必须**落 output/查询导出/ 子目录 —— 因为 find_latest_result() 只 glob output/ 一层、
#    且靠文件名里的 8 位日期筛候选。查询导出表名天然带日期，一旦落根下就会被当成「最新结果文件」，
#    把飞书导出的目标劫持到一份查询结果上。_smoke_query.py ⑦ 已把这个场景做成反证断言。
# 2) 🔒 查询 / 导出链路是**纯读链路**：刻意完全不碰 STATE_LOCK / STATE / paths.ENRICH_FILE。
#    STATE_LOCK 是非可重入 Lock、log() 内部也抢它 → 长查询若占锁会卡死采集、落盘、轮询；
#    导出另用独立的 EXCEL_LOCK。改这块代码时不要「顺手」去读 STATE。
# 3) 🏷️ 筛选选项必须读**真实库** distinct（db_facet_counts），页面**零硬编码行业名**。
#    库里混着历史行业名（家具家居 18 条 / 汽配 5 条），硬编码关键词库那 8 个规范值会让这些数据
#    「怎么选都筛不出来」。空值用哨兵 `QUERY_EMPTY='__empty__'`（前端 `const EMPTY` 与后端一字不差，
#    _check_page.py R9 有断言）—— 否则「勾了未填写却筛不出东西」是静默失效。
