# 2026-10-06

## 新增：海关商品编码采集（stats.customs.gov.cn → XLSX）

用户问「能不能从 http://stats.customs.gov.cn/ 拿到商品编号+商品名称，存成 XLSX，查询后有 8969 条」，
并贴了「参数查询」结果页的 HTML 当证据（第 15 页 / 共 45 页 / 200 条一页）。

### 实测结论（重要，下次一定还会遇到）

- 站点挂的是**瑞数信息动态防护**：普通 HTTP 客户端一律返回 **412**，响应体是 `$_ts` 变量
  + 混淆 JS（`/Qy6JDI4LYvbD/….js`）+ meta refresh + `SF_cookie_251`。
  **纯 requests / urllib 拿不到任何数据**，只能走真浏览器（项目现成的 DrissionPage
  + Playwright Chromium，一次就过）。
- 入口：`GET http://stats.customs.gov.cn/queryData/selectCodeTs`，**服务端整页渲染**（不是 AJAX）；
  菜单里的入口是 `/paramManager/selComplexList`（商品参数）。
- 取数配方：在 `#Search_form` 里设 `codeLength=8` + 勾 8 位 radio + `pageSize=200`
  + `yearId=2025` + `codeTsList=''` + `searchKey=''` + `pageNum=n` → `form.submit()` → 整页跳转。
- **两个参数闸门**：`yearId='2025'` → **8969** 条；`yearId=''`（不限年份）→ **104238** 条 / 522 页。
  `pageSize` 页面默认是 **10**（不是 200），不显式设会变成 897 页。
- 条数核对：8969 条 / 45 页（44×200 + 末页 169）；首行 `01012100 改良种用马`，
  末行 `99000000 跨境电商B2B简化申报商品`。
- **名称必须取 `title` 属性**：可见文本被 CSS 截断（8969 条里 35 条形如 `…`），`title` 才是全名。

### 踩坑

1. **`page.run_js` 里裸 IIFE 没有外层 `return` 会拿不到返回值** → 被误判成「找不到 `#Search_form`」。
   必须写成 `return (function(){…})();`。
2. **只判断「表格有没有行」会读到上一页的数据**：提交后的一瞬间旧 DOM 里还留着上一页的行 →
   静默错页。改成「`hidPageNum` 等于目标页号 **且** 行数 > 0」才算就绪。
3. **Bash heredoc 里的 `\\` 会被改写**：写 `.bat` 时路径变成了 `D://waimao//dp`。
   改用 `Write` 工具落 `.bat` 就正常（实测按 **GBK** 写出，与既有两个 `.bat` 一致，无需再手工转码）。
4. 写文件前忘了 `makedirs` → `FileNotFoundError`；已补 `_ensure_out_dir()`（建不出退回 `output/`）。
5. **站点握手上会偶发吐 39 字节空文档**（`<html><head></head><body></body></html>`），
   **不是被封**（同一时刻 `requests` 仍拿到标准 412 挑战页）；空文档不会自愈 →
   必须**重新导航**重试。`_open()` 已改成 4 轮重开 + 每轮最多 20s 轮询。
6. `--dry` 不能走「缓存全命中 → 直接汇总」那条路（会真的写出文件）；已在前面加了
   独立的 dry 快捷分支：缓存里有第 1 页就直接报告总数、**连浏览器都不开**。
