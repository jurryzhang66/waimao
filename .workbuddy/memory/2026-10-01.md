## 新增「客户库查询」页面 `/db` + Excel 导出

**用户需求**：做一个数据库查询 + 导出页面。筛一个国家/行业等条件 → 按查询看结果 → 没问题就导出 Excel。并让我「根据数据库的结构推荐筛选条件」。
**拍板结果**（AskUserQuestion，4 项全选「推荐」）：① 筛选 = 全套实用筛选（关键词 / 行业 / 国家 / 来源 / 评级 / 评分区间 / 有无邮箱电话联系页 / 采集时间范围 / 排序 + 分页）② 导出列 = **客户库全字段**（不是结果表那 10 列）③ 文件去向 = 存档 + 浏览器下载 ④ 飞书暂时不用，只要 Excel。

**做法**：
1. `core/db.py` 加「客户库查询」整段：`_query_where()`（关键词 9 字段 LIKE + 多选 IN + 空值哨兵 + 评分区间 + 联系方式白名单片段 + 采集时间范围）、`db_query_customers()`（计数与取行共用同一 WHERE，返回 `(total, rows, limit)`）、`db_facet_counts()`（四维度 distinct+count + 各自空值条数 + contact 六口径 + score/date min·max）。
2. `core/paths.py` 加 `query_export_dir()` / `build_query_export_name()` / `ts_query_export_path()`（**必须落 `output/查询导出/` 子目录**，理由见下）。
3. `core/ui.py` 抽出 `_page_style()` / `_read_sub_template()` / `_inject_page_style()`，新增 `QUERY_HTML` —— 三个页面共用 `page.html` 的样式，`page.html` **一字节不动**（sha256 锁）。
4. `ui/query.html`（约 470 行）：筛选条件卡 + 结果表卡；行业/国家/来源/评级**零硬编码**，全部由 `/api/db/facets` 动态渲染。
5. 入口加 5 个路由（`/db`、`/api/db/facets`、`/api/db/query`、`/api/db/export`、`/api/db/download/<name>`、`/api/db/open_folder`）+ `_save_query_excel()`（14 列）。
6. `ui/manual.html` 顶部加「📊 客户库查询」入口链接（page.html 不能动，这是唯一入口）。
7. `.gitignore` 加 `output/查询导出/`。

**三条关键技术判定**：
- ⛔ **导出必须落 `output/查询导出/` 子目录**：`find_latest_result()` 只 glob `output/` 一层、按文件名 8 位日期筛候选 → 查询导出表名天然带日期，落根下会被当成「最新结果文件」，**劫持飞书导出目标**。`_smoke_query.py` 已把这一场景做成反证断言。
- 🔒 **查询/导出是纯读链路**，刻意不碰 `STATE_LOCK` / `STATE` / `paths.ENRICH_FILE`（非可重入锁 + 长查询占锁会卡死采集），导出另用独立 `EXCEL_LOCK`。
- 🏷️ **筛选选项读真实库 distinct**、页面零硬编码行业名（库里有历史行业名 `家具家居` 18 条 / `汽配` 5 条），空值用哨兵 `QUERY_EMPTY='__empty__'`（前后端一字不差，`_check_page.py` R9 有断言）。

**验证（全绿）**：
- `.workbuddy/_smoke_query.py` ★新建★ **10 组 126 项**（全跑临时库 + 临时 output）。
- `.workbuddy/_check_query_ui.py` ★新建★ 真机 A–G 全过，截图 `.workbuddy/_query_ui.png`（142KB）。
- `_check_page.py` 加 R9 后 R1–R9 全绿。
- `.workbuddy/_run_all_reg.py` **22 项全 EXIT=0（68.2s）**；真实库复核 **292 条**（谷歌搜索 214 / 手动采集 71 / 谷歌地图 7）、`website_key` 错位 0、测试域名残留 0、`output/查询导出/` 空。
- 已同步 `AI_PROJECT_CONTEXT.md`（新增 M13 + §1.4/§2/§4.1/§5/§8/附录）与 `.workbuddy/_reg_summary.txt`（22 项版）。

**调试中踩到的坑（都是测试脚本自身的）**：`%` 作为 LIKE 通配符参数化**不转义**（断言写错）；反证用的占位结果表要写**比导出旧**的日期否则反证失效；`send_file` 响应持句柄要先 `close()` 才能删文件；`<select>` 程序化赋值不存在的 value 会被浏览器忽略；样本全都有行业时「未填写」哨兵项正确地不显示（要补一条无行业的样本）。
