4. 参数

数据源：
地图名录里只有「有实体地址的真实商家」，所以 B2B 名录站/新闻站/菜谱站不会混进来；电话和地址是地图直接给的，官方有官网的再访问官网补邮箱。
⚠️ 单次搜索上限约 120 条；结果受出口 IP 所在地影响，指定城市能明显提高精度。仅用于少量内部研究。
城市名会拼进地图搜索词（谷歌官方推荐的位置限定方式），比只选国家精准得多

本轮最多新增多少个新客户（10-100）；按新增个数计，不按是否抓到联系方式计。SQLite 客户库总量不设上限
搜索方式：
勾选：每搜到一个新客户，立刻访问它抓邮箱/电话并评分，抓完（或确认抓不到）再搜下一个，凑够数量即停。每条会多花几秒，但不用等全部搜完；结果文件在整轮结束时一次写出。
不勾：只收集网站线索，邮箱电话留空，速度快，适合先铺量，稍后再双击「补历史欠账.py」批量补。
（地图模式下：地图本来就给电话和地址，不勾就是不再访问官网补邮箱。）
排除条件（勾选要排除的，默认全排除）
中国商家过滤（默认全部勾选，可逐项关闭）
地图模式没有查询公式，所以「排除 China manufacturer」这类查询词选项不生效；但「中文地址 / +86 电话 / 平台域名」这些在结果上判断的项照常生效
